小计金额 = 数量 × 预计单价；合计金额 = 小计金额 + 运费，都由系统自动算。 单价超过 1000 元的行会标黄，记得准备合同。 下单与发票状态在锁定本轮之后照样能改（下单、收发票本来就发生在汇总之后）。 发票支持 PDF 和 jpg / png / bmp / tif 图片（手机拍的照片也行）—— 图片会自动转成 PDF 归档，合并打印时一视同仁。 照片和扫描件会再试一次 OCR 认金额：认出来只是建议值，请对一眼票面。
