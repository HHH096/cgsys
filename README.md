# 电气组采购系统

组员在网页上填「我要买什么」→ 采购同学汇总下单 → 收发票 → 合并打印 → 导出「车队总表」的行块。
**取代**原来那份共享在线表格手工填的流程。

> 纯 Python + 原生前端，**没有构建步骤**、没有数据库服务要装（用 SQLite 单文件）。
> 一台电脑 / 一台小服务器就能跑，局域网里十来个组员同时用没问题。

---

## 1. 它解决什么问题

- **组员自己填**：手机上把淘宝分享文案一粘，名称/链接/价格自动识别，不用再@采购同学转达
- **不会漏票**：每一轮都有「缺发票清单」，退过货的自动排除；谁还没交票一目了然
- **票和账对得上**：一张发票可以挂多条目（淘宝一单买几样），合并打印时按**发票**去重，不会重复报销
- **给车队总表省事**：导出「行块」，列顺序与总表新表头逐列一致，整段复制粘过去就行
- **自动读金额**：电子发票直接从 PDF 文字层读「价税合计」；照片/扫描件会再试一次 OCR

## 2. 最快跑起来（Windows 单机）

1. 装 **Python 3.8+**（安装时勾上 *Add Python to PATH*）
2. 双击 **`启动.bat`** —— 第一次运行它会自己建 Python 环境、装依赖（约 1 分钟，需要联网），然后起服务
4. 浏览器打开 `http://127.0.0.1:8000/purchase` —— **第一次会让你设一个采购密码**

   > 这个密码只有负责采购的同学需要知道，别写进任何文件。

5. 在采购入口的「**分享给组员**」里，把局域网地址 / 二维码发给组员（他们要和这台电脑连同一个 WiFi）
6. 在「**组员管理**」里把名单加齐（或者直接编辑 `组员名单.txt`，见第 5 节）

其他几个 `.bat` 是配套的小工具：`停止服务.bat`、`后台启动.bat`、`备份数据.bat`、`开启开机自启.bat`。

## 3. 部署到云服务器（Linux）

```bash
# 1) 把代码放上去
scp -r . root@<你的服务器IP>:/opt/cgsys

# 2) 装依赖（用 venv 隔离）
cd /opt/cgsys
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 3) 装 systemd 单元（仓库里的 tools/cgsys.service 可以改改就用）
cp deploy/cgsys.service /etc/systemd/system/
systemctl daemon-reload && systemctl enable --now cgsys
```

- **端口默认 8000**，要对外访问就得在**云控制台的安全组**里放行它（机器本身没开防火墙）
- 更新代码：传文件上去 → `systemctl restart cgsys`
- 看日志：`journalctl -u cgsys -n 50 --no-pager`

### 可选：让照片发票也能自动读金额（OCR）

```bash
# Debian/Ubuntu
apt install -y tesseract-ocr tesseract-ocr-chi-sim
# CentOS/RHEL/Alibaba Cloud Linux
dnf install -y tesseract tesseract-langpack-chi_sim
```

没装也能用：传照片时会直接问你金额，手填一下即可（**这是刻意的**——图片没有文字层，读不出就别猜）。

## 4. 两个入口

| 谁用 | 地址 | 要什么 |
|---|---|---|
| 组员（填需求、传发票） | `http://<地址>/` | 组员口令（全组共用一个）+ 选一次「我是谁」 |
| 采购（汇总、下单、收票、导出） | `http://<地址>/purchase` | 采购入口密码 |

**权限在后端硬卡**，不是把按钮藏起来：组员只能改/删自己填的条目，采购专用接口没登录一律 401。

## 5. 配置

### 组员名单

放在根目录 `组员名单.txt`，每行一个人；**行首加 `*` 表示采购负责人**：

```
*张三,13800000000
李四,13900000000
王五
```

- 逗号、中文逗号、制表符、空格都能当分隔符；手机号可以留空；`#` 开头是注释
- 名单只在**第一次把人加进来**时生效；**已经存在的人，负责人标记只认界面上改的**
- 仓库里附了 `组员名单.example.txt`，复制成 `组员名单.txt` 改就行

### 口令 / 密码

都在界面上设，**不写在文件里**：

- **采购密码**：第一次进 `/purchase` 时设置；忘了就删掉 `data/settings.json` 重设
- **组员口令**：采购入口 →「分享给组员」→ 设一个全组共用的口令；**留空保存 = 关掉组员入口**

### 邮箱自动收发票（可选）

采购入口 →「邮箱收发票」→ 填 IMAP 服务器、账号、**授权码**（不是登录密码）。
QQ 邮箱在「设置 → 账号 → IMAP/SMTP 服务」里生成；163 在「设置 → POP3/SMTP/IMAP」。

## 6. 一轮采购怎么走

1. **建轮次**（采购入口 → 「+ 新建轮次」，比如"十月采购"）
2. **组员填** —— 直接粘淘宝分享文案，系统认名称/链接/价格；填完点「保存条目」
3. **采购汇总** —— 「锁定本轮」（锁定后组员不能再改内容，但下单/收票不受影响）→ 导出采购表
4. **下单 → 收发票** —— 条目行上改「下单状态」；发票可以在行里传（PDF 或照片都行），也可以从邮箱收
5. **一票多条** —— 一张票盖了好几样时，点「改挂」勾上对应条目；金额按条目分
6. **合并打印** —— 发票正面 + 背面采购信息，A4 每页 N 张，双面打印选「长边翻转」
7. **回填总表** —— 复制「行块」，粘到车队总表对应月份 sheet 的「电气组」那一块末尾

## 7. 目录结构

```
app/
  main.py            启动入口（python app/main.py [端口]）
  config.py          路径与常量
  core/              业务逻辑
    db.py            SQLite 表结构 + 迁移
    repo.py          数据访问
    rules.py         金额计算、校验、拆分规则
    exporter.py      导出三张 sheet
    blockexport.py   回填总表用的行块 + 对账
    invoicepdf.py    发票排版 + 读金额/明细（含 OCR 兜底）
    invoicing.py     发票归档与命名
    invoicematch.py  发票明细 → 采购条目 的匹配
    mailfetch.py     邮箱收发票（IMAP）
    settings.py      口令 / 密码 / 登录态
  server/api.py      FastAPI 路由
  web/               index.html / app.js / styles.css（原生，无构建）
tests/               unittest 测试
```

## 9. 常见问题

**问：组员打不开网页？**
答：先确认和主机在**同一个局域网**；如果是云服务器，检查**安全组**有没有放行端口。

**问：发票传上去了，实付金额还空着？**
答：那张票是照片/扫描件（没有文字层）。系统已经装了 OCR 时它会自己试读一次；读不出就点行里的「填金额」手填。

**问：一张发票买了好几样，怎么办？**
答：把票挂到其中一条，再点「改挂」把其它条目也勾上——**合并打印时这张票只印一次**，不会重复报销。

**问：导出时「低于一千 / 高于一千」是怎么分的？**
答：按**同一商家本轮合计**：同一链接（或同一商家名）的几笔加起来 ≥ 1000 就整组进「高于一千」（这类通常要签合同）。阈值建轮次时能改。

**问：数据存在哪？想备份？**
答：全在 `data/` —— `procurement.db`（SQLite）+ `invoices/`（发票原件）+ `settings.json`（口令）。
**整个 `data/` 目录拷走就是完整备份**；`备份数据.bat` 就是干这个的。

## 10. 说明

给车队/电气组内部自用的小工具，**没做多租户、没做细粒度权限**——
真正的边界只有一条（服务端强制）：**采购专用接口必须已登录**。
组员之间的隔离是"君子协定"级别：防手滑改错别人的东西，不防存心使坏。

组别名、表格标题这类硬编码在 `app/config.py` 里，换成别的组改这两个常量即可。
